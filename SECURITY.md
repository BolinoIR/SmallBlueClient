# Security policy

`.sbc` files are authenticated browser-session credentials. Treat them like a
password: do not paste, attach, commit, or include them in issue reports.

To report a security issue, open a private GitHub security advisory for
`BolinoIR/SmallBlueClient` or contact the maintainer through GitHub. Include a
minimal reproduction with every session token, cookie, meeting identifier, and
user identity removed.

Supported release line: **0.2.x**.
